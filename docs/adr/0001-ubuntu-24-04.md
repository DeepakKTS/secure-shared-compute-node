# ADR 0001: Target Ubuntu Server 24.04 LTS

Status: accepted

Context: DASH hardware and OS are unknown. Research servers most often run Ubuntu LTS. The lab must reflect the likely target.

Decision: Ubuntu Server 24.04 LTS on all lab VMs.

Consequences: Must handle 24.04 specifics: SSH socket activation, cloud-init sshd drop-ins, needrestart prompts, /tmp not being tmpfs by default. See `.claude/skills/ubuntu-24-gotchas`. If DASH runs another distro (Rocky, Debian), roles need OS-family branches; keep OS-specific tasks isolated in `tasks/<os_family>.yml` to make that easy.
